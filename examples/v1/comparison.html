The same counter in v1 and v2

Both programs show a count and its doubled value, with decrement, increment, and quit buttons. They use the same cyan text, spacing, and padding. Each listing includes its imports and application setup.

v1 · signals and a surface

import {
  Button, computed, HStack, Renderer,
  state, Surface, Text, VStack,
} from "canto";

const count = state(0);
const label = computed(
  () => `Count: ${count.get()} · Doubled: ${count.get() * 2}`,
);

const view = VStack(
  Text("Counter").style({ bold: true }),
  Text(label),
  HStack(
    Button("−").props({
      onPress: () => count.set(count.get() - 1),
    }),
    Button("+").props({
      onPress: () => count.set(count.get() + 1),
    }),
    Button("Quit").props({
      onPress: () => surface.dispose(),
    }),
  ).style({ gap: 2 }),
).style({ gap: 1, padding: 1, foreground: "cyan" });

const surface = new Surface(view, new Renderer(), {
  disableConsole: true,
});
surface.startRender();

State lives outside the view. A computed signal supplies the derived label; Surface and Renderer own rendering and disposal. This listing targets the archived v1 API.

v2 · component state and an app

import {
  button, column, createApp, row,
  text, useApp, useState,
} from "canto";

function Counter() {
  const [count, setCount] = useState(0);
  const app = useApp();

  return column(
    text("Counter").bold(),
    text(`Count: ${count} · Doubled: ${count * 2}`),
    row(
      button("−", () => setCount(n => n - 1)),
      button("+", () => setCount(n => n + 1)),
      button("Quit", () => app.stop()),
    ).gap(2),
  ).gap(1).padding(1).color("cyan");
}

await createApp(Counter, { mode: "inline" }).run();

State belongs to the mounted component. Derived text is ordinary TypeScript; run() owns terminal cleanup and resolves when the app stops.

For this small app, both APIs are compact. v2 removes explicit computed signals and separate rendering objects; it adds a component function and state setter. Hooks must keep a stable order, and a component executes again when its state changes.
