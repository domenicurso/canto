# Frame inspector and performance

[Documentation](../README.md)

Every app includes an inspector, hidden initially. F3 toggles it; Escape cancels picking or closes it. Its gray, borderless UI is built from Canto components in a separate mounted tree, so its controls and scrolling use the same runtime as your application without appearing in the inspected tree. `{ debug: false }` releases F3 and Ctrl+Shift+I while retaining programmatic access through `app.debug` and `useApp().debug`.

Choose Elements to browse the mounted tree, or Pick to hover application content and click a node. Ctrl+Shift+I also toggles picking. Colored regions distinguish content, padding, borders, and space between flow children. The tooltip reports actual cell geometry; Canto has no margin property. The tree scrolls on both axes without truncating labels or capping indentation. Scroll or drag its scrollbars, navigate with arrows and Home/End or Page Up/Down, and collapse or expand with Left/Right. Layout, Styles, Props, and State expose the selected node's geometry, resolved appearance, declared styles and variants, props, callbacks, hooks, and interaction state. Property values wrap within their own scroll region. Tab moves between inspector scroll regions; clicking application content returns keyboard navigation to the application.

The header keeps Stats and Elements on the left and Pick, placement, and Close on the right. Sidebar reserves real layout space and makes `useViewport()` report the remaining columns; Overlay leaves the viewport unchanged. Sidebar falls back to an overlay below 50 terminal columns and returns when space is available. Closing restores the application's width and preserves its state and focus. Use `app.debug.setPlacement("sidebar")` or `setPicking(true)` to control these modes from application code.

FPS and viewport size sit above two columns: content preparation and painting on the left, completed frame and terminal costs on the right. Below 8 FPS, each new content frame publishes immediately, including isolated hover, press, and release updates. Faster streams refresh at most four times per second, retaining the actual content frame with the most changed cells (breaking ties by CPU time) and the actual completed frame with the highest total latency. No values are averaged: `Content #N` identifies the frame for CPU and exact work counts, while `Output #M` identifies the completed frame for total, inspector, encoding, write, interval, and byte measurements. Output completion cannot be known while painting the current panel, so its frame ID is separate. FPS counts completed adapter presentations in the last second. During busy streams, the entire inspector tree and its diagnostic traversal refresh at most four times per second; intervening frames reuse its retained surface. Inspector input and viewport changes refresh immediately. The inspector redraws only with app frames, so idle apps do not gain a diagnostic animation loop.

`app.stats` exposes an immutable measurement of the most recently completed frame. `contentTime` includes view reconciliation, style/layout preparation, painting, native raster preparation, and the content cell diff. `debugTime` includes inspector composition, its rasters, and the final cell diff. `presentTime` includes the complete adapter call. The process adapter additionally reports native encoding time, stream write/backpressure time, and output bytes. `renderTime` spans reconciliation through completed output; `intervalTime` measures completion-to-completion spacing, including idle and timer delays. Adapter completion cannot measure the terminal emulator's GPU display latency. Injected adapters may expose `presentation` measurements; unavailable metrics display a dash.

Content cell changes exclude the inspector, while `cellsWritten` includes its actual terminal cell updates. Native uploads are measured separately in output bytes. Layout nodes and painted cells describe work performed, so cached layout can report zero nodes even with a full-screen canvas animation. Pointer motion within an unchanged target does not schedule a frame; hover transitions, dragging, and reactive mouse handlers still update normally.

See [stats field definitions](../api/diagnostics.md), [terminal limitations](../reference/compatibility.md), and [testing](testing.md).

## Editing elements

The Elements tree highlights names, strings, numbers, and literals. Click a breadcrumb to select an ancestor. The Layout tab includes a visual border, padding, and content diagram in terminal cells; the gray sidebar itself stays borderless. Scrollbar tracks blend into the panel, and thumbs appear while hovering their scroll region.

Click a layout or style value, text, supported native prop, component prop, or state hook to edit its JSON representation. Plain JSON objects and arrays are editable; callbacks, accessors, and non-JSON values stay read-only. Enter applies the value; Escape cancels. Invalid input stays in the editor with an error. Every number in the box model opens a numeric editor, including individual border and padding sides, content and outer dimensions, and row/column gaps. Terminal borders are zero or one cell wide.

Changes are temporary mounted-node overrides and survive application renders; state edits use the existing state setters. Each changed property has its own reset control; Reset in the tab bar clears all edits on that node. Removing the node discards its overrides. Tabs, placement, and selection persist across renders and responsive pane changes; keyed equivalent remounts recover the selected path. Edits never write source files.

## Developing the inspector

Run `bun run dev:inspector` to open the internal [inspector fixture](../../src/runtime/inspector/fixture/app.ts). It mounts the production `InspectorView` as application content, so F3 opens an independent inspector that can pick the fixture's actual buttons, tree rows, property editors, and layout. Close the outer inspector with F3 to return to the preview.

The top row switches between Sample, Long tree, Values, and Empty cases. Use the preview's own tabs, Pick, and Sidebar/Overlay controls to exercise its states; Reset clears temporary edits and restores the initial selection, and Open restores a closed preview. Resize the terminal or dock the outer inspector to check narrow layouts. Stats uses fixed readings so its labels stay stable while designing. Sample descriptions live in [sample.ts](../../src/runtime/inspector/fixture/sample.ts); appearance changes belong in the production inspector components alongside the fixture directory. This entry point is internal and adds no package exports.

Run `bun run bench:inspector` to compare hidden and Elements inspector overhead over a 1,000-row application. It reports median and p95 `debugTime` after warmup, including surface refreshes and cached composition.
